# 🛡️ CyberShield - Phishing Detection
Live Demo: https://cybershield-final-rho.vercel.app/

## What is this?
AI tool to detect phishing URLs. Paste any suspicious link, it tells if Safe or Phishing with Risk Score 0-100.

## Features
- URL Scanner - 30+ checks, Risk Score
- Email Scanner  
- Awareness Hub - Learn about phishing
- Quiz Module
- Explainable AI - Tells WHY it's phishing

## Tech Stack
Next.js 14, React, Tailwind CSS, Python ML, Vercel

## Live Link
https://cybershield-final-rho.vercel.app/

## How it works
User enters URL -> Feature Extraction (IP check, @ symbol, long URL, subdomains) -> Risk Score -> Result Green/Yellow/Red

## Accuracy
96.4% - Random Forest Model
